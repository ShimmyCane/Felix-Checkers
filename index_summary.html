🗺️ System Architecture

How index.html coordinates the client-side styling, synthesizer audio, checkers engine, and touch controller:

📄 index.html

Main Application Shell: Renders semantic DOM, 8x8 grid coordinates, turn indicator, actions, and settings drawer.

🎨 style.css

Visual System: Light pastel palette, 3D radial piece gradients, iPad touch sizing, responsive layout, and bounce animations.

🔊 audio.js

Web Audio Synthesizer: Zero-dependency sound effects for clicks, captures, king promotions, and victory fanfare.

🧠 game.js

Core Logic Engine: 8x8 matrix state, 2-row/3-row setups, jumps, kinging, Felix chess pieces, and kid-friendly AI.

🎮 app.js

Interaction Controller: DOM event listeners, piece selection, AI move orchestration, drawer controls, and win popups.

⚙️ Adjacent Files: Variables, Definitions & Tweak Guide

All core settings and adjustable variables across style.css, game.js, audio.js, and app.js:

🎨 1. style.css Variables (:root)

Control the visual theme, board dimensions, colors, and iPad touch dimensions:

Variable Default Value What It Controls How to Tweak It
--sq-light #FFF9EE Color of light board squares (where Felix chess pieces start) Change to any pastel cream, peach, or light wood tint.
--sq-dark #7CA992 Color of dark board squares (where standard checkers move) Change to pastel navy, plum, or slate for alternative board themes.
--piece-red #FF6B6B Primary color of Red team checkers Tweak to coral, crimson, or amber.
--piece-black #343A40 Primary color of Black team checkers Tweak to royal midnight blue or deep forest charcoal.
--board-max-size min(84vw, 76vh, 600px) Maximum board size for iPad screens Adjust the maximum cap (e.g. 680px) to resize the board for larger tablets.

🧠 2. game.js Engine State & Parameters

Configures rules, piece counts, turn mechanics, and coordinates:

Property / Variable Allowed Values Description Effect of Changing
rowsOption 2 or 3 Number of starting checker rows per player 2 spawns 8 checkers (faster kid game); 3 spawns 12 checkers (classic).
variant 'standard' | 'felix' Game mode identifier When set to 'felix', initializes Queen on D1/E8 and Bishops on B1, F1 / C8, G8.
board[r][c] Object or null 8x8 board matrix storing piece objects Piece object structure: { player: 'red'|'black', type: 'checker'|'queen'|'bishop', isKing: boolean }.
isMultiJumping true | false Enforces multi-jump turn persistence Locks player selection to the jumping piece until all available jump captures are completed.
AI heuristic scoring Numbers (5 to 25 pts) Scores evaluated in getBestAIMove() Queen capture = +20, Bishop = +12, King = +8, Promotion = +5. Tweak to make AI easier or harder.

🔊 3. audio.js Synthesizer Parameters

Frequencies and waveforms used for browser sound generation:

Method Waveform & Frequency Duration Tweak Recommendation
playMove() triangle: 320Hz → 160Hz 0.08s Simulates tactile wooden click. Lower to 240Hz for a heavier clack.
playCapture() sine: 440Hz → 880Hz 0.16s Joyful rising sweep on capture. Increase pitch for higher playful sound.
playKing() triangle: [523Hz, 659Hz, 784Hz] 0.22s Ascending royal arpeggio (C5, E5, G5).
playWin() sine: [523Hz, 659Hz, 784Hz, 1046Hz] 0.35s Celebratory fanfare (C5, E5, G5, C6).

🎮 4. app.js Controller Variables

UI synchronization, event timing, and user preferences:

Variable Default Role Tweak Possibility
currentConfig { rowsOption: 3, variant: 'standard', opponentType: 'pvp' } Active game parameters applied to the engine Can be updated dynamically via the settings drawer.
isAiThinking false Input blocker during computer turns Prevents accidental touch events on the iPad while the computer is calculating.
AI delay timeouts 600ms & 350ms Pacing delays for computer moves Adjust between 300ms (faster) and 900ms (more suspenseful for children).
